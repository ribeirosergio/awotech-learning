# Arduino runtime

Nesta etapa, exporta somente contratos da IR, diagnósticos e eventos para o LED. Não há parser nem execução de código. A próxima etapa implementará uma gramática limitada e rejeitará sintaxe não suportada com mensagens pedagógicas; sem `eval` ou compilação C++ completa.

Variáveis, condicionais, bibliotecas e funções auxiliares das aulas seguintes exigem evolução deliberada do subconjunto. Consultar `docs/analise-apostila.md` antes de implementar os exemplos.
