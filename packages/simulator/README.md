# Simulador

Nesta etapa, exporta somente contratos de componentes, conexões, circuitos e estado. Não há engine, validação de circuito ou cálculo elétrico implementado.

A próxima etapa separará o validador de montagem do runtime, consumirá eventos Arduino e atualizará o estado lógico. A UI desenhará componentes e fios a partir desse estado. O laboratório será guiado e específico por atividade.
